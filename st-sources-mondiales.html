À quoi elles servent dans un diagnostic.

  • Confronter une hypothèse. Avant de retenir une cause, vérifier qu’elle est décrite ailleurs, dans quelles conditions et avec quelles limites.
  • Savoir ce qu’une presse peut remonter. Les spécifications EUROMAP et OPC UA décrivent les données échangeables ; elles ne garantissent pas leur présence sur une presse donnée.
  • Comparer sans extrapoler. Les jeux de données ouverts permettent de tester une méthode ; ils ne remplacent pas les cycles de votre atelier.
  • Ne pas transposer à tort. LSR, extrusion, latex ou compression ne se transposent pas à l’injection de mélanges solides sans essai ; la colonne Limites le signale.

Règles de lecture.

  • Plusieurs documents d’un même fabricant comptent pour une seule confirmation (par exemple les deux guides BASF).
  • Une prédiction ou une importance de variable n’est pas une cause physique démontrée.
  • Un taux de gain publié vaut pour le site, la pièce et la fenêtre étudiés ; il ne s’extrapole pas.
  • Une spécification d’échange ne dit pas quelles données une presse remonte réellement : cela se vérifie machine par machine.
  • Les jeux de données sous embargo sont cités pour leurs métadonnées seulement.
