# Simulator language editions

The French pages are the reference edition. The English interface uses a local dictionary: no page content, form inputs or case data is submitted to a translation service. Settings, case identifiers and calculations remain in the original application. Existing recorded media and downloadable reference documents have not been dubbed or replaced.

Initial English wording was generated offline using the Argos French-to-English package (1.9), based on OPUS-MT by Jörg Tiedemann and Santhosh Thottingal, with editorial changes to launcher and industry terminology.
